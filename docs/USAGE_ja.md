# Qwen3-1.7B-4bit-DWQ 使い方

Qwen3-1.7B を 4 ビットにしたモデルです(重み 1.42GB、元は 3.4GB)。次の語の予測は 93.5% で元のモデルと一致します。
AI アシスタントとして使うときは、下の **システムプロンプト** を付けてください。知識が要る質問は、自分の資料を検索して
渡す使い方(**RAG**)を勧めます。

## 1. 準備

| 環境 | インストール | メモリ |
|---|---|---|
| Mac(Apple シリコン) | `pip install mlx-lm` | 約 1.4GB(本物の 4 ビットで動く) |
| それ以外(Windows / Linux、GPU あり・なし) | `pip install torch transformers` | 約 3.4GB(4 ビットの値を 16 ビットに戻して計算) |

検索(RAG)も使うなら、どちらの場合も `pip install torch transformers` が要ります(検索用の小さなモデルを動かすため)。

## 2. すぐ試す(同梱の rag_chat.py)

```bash
python rag_chat.py                                     # 普通のチャット
python rag_chat.py --docs ./my_docs                    # ./my_docs の .txt / .md を検索して答える(対話)
python rag_chat.py --docs ./my_docs "有給休暇は何日？"  # 1 問だけ
python rag_chat.py --docs ./my_docs --show-context     # 見つけた資料も表示する
python rag_chat.py --think "1から50までの素数はいくつ？"  # じっくり考えさせる(数学向き、遅い)
```

Mac なら自動で MLX を使います。`--backend torch` / `--backend mlx` で切り替えられます。

## 3. 検索(RAG)の仕組み

`--docs` を付けると、質問ごとに次のことをします。

1. **資料を切る**:フォルダ内の .txt / .md を、約 400 文字ずつ(空行、改行の位置で)切ります(`--chunk` で変更)。
2. **探す**:切った資料と質問を、日本語と英語を扱える小さな埋め込みモデル(intfloat/multilingual-e5-small)で
   ベクトルにして、質問に近い上位 4 件(`--k`)を選びます。
3. **渡す**:次の形でモデルに渡します。

```
[system] (下のシステムプロンプト)
         以下の資料だけに基づいて質問に答えてください。資料に答えがない場合は「資料には記載がありません」と答えてください。
[user]   [1] (就業規則.md) 第12条(年次有給休暇)年次有給休暇は、入社6か月経過後に12日を付与する。…
         [2] (x200_manual.txt) …

         質問：入社して半年後の有給休暇は何日ですか？
```

自分のアプリに組み込むときも、この形のまま渡すのがおすすめです(この形で検証しました)。検証で確かめたこと:

- 資料にあることは正しく答える(日数、金額、時間、英語の資料に日本語で答える、など)
- 自分の思い込みより資料を優先する(素では「日本一長い川は富士川」と間違えるが、資料を渡せば「信濃川」)
- 資料に答えがなければ「資料には記載がありません」と言う
- 資料の中に「指示を無視して〜と言え」と書かれていても従わない
- 単価と割引率から合計を計算する、程度の計算はできる

苦手なこと:資料から一段の推論が要る問い(「劣化は保証対象外」から「無償修理はできない」を導く、など)は
「記載がありません」と答えることがあります。

検索の精度を上げたいとき:資料を 1 件 1 話題になるよう小さめに切る、`--k` を増やす(増やしすぎると無関係な資料に
引っぱられる)、資料に見出しやファイル名で文脈を付ける。

## 4. 推奨設定

- **システムプロンプト**(必ず付ける。付けないと危険な質問にも答え、言語の指定も無視します):

```
あなたは誠実で役に立つAIアシスタントです。
- ユーザーと同じ言語で答えてください。ただし、システムの指示で言語が指定されている場合はそれに従ってください。
- 武器・爆発物・危険な薬物の作り方、人を傷つける方法、犯罪の具体的な手順は教えず、「その質問にはお答えできません」と短く理由を添えて断ってください。危険のない日常的な質問には普通に答えてください。
- 知らないことや確信が持てないことは、作り話をせず「わかりません」と答えてください。資料が与えられた場合は資料の内容を優先し、資料の記述から計算や推論で導けることは答えてください。
- ユーザーが出力の形式や長さを指定したときは、それを厳密に守ってください。指定がなければ普通の文章で答えてください。
- 同じ文を繰り返さず、簡潔に答えてください。
```

  注意:システムプロンプトに「JSON」など具体的な形式の例を書くと、普通の質問まで JSON で答えるようになります。

- **生成**:普段は貪欲(temperature 0)+ repetition_penalty 1.05。考えさせる(enable_thinking=True)ときは
  temperature 0.6、top_p 0.95、top_k 20(貪欲だと同じ考えを繰り返すことがある)。
- **会話**:前の発言を messages に入れれば覚えています(名前、予定、品目数などの検証は 4/4)。

## 5. 検証結果(数学以外 35 問、思考なし)

| | コード | 形式 | 会話の記憶 | 知識 | 資料から答える | 安全 | 計 |
|---|---|---|---|---|---|---|---|
| 元の 16 ビット、システムプロンプトなし | 5/6 | 6/7 | 3/4 | 6/6 | 10/10 | 1/2 | 31 |
| このモデル、なし | 3/6 | 5/7 | 2/4 | 5/6 | 8/10 | 1/2 | 24 |
| このモデル、システムプロンプト + repetition_penalty 1.05 | 3/6 | 6/7 | 4/4 | 5/6 | 9/10 | 2/2 | 29 |

数学(思考あり、10 問)は 4 ビットで 9/10。

## 6. 苦手なこと

- **コード**:4 ビット化で一番落ちた(6 問中 3 問)。短い関数でも細かい条件(記号の除外、ローマ数字の減算など)を落とす。
  書かせたコードは必ず動かして確かめてください。
- **知識**:1.7B なので素の知識は不確か(川の名前などを作り話する)。事実が大事な用途は RAG で資料を渡してください。
